# Incident Response Policy

## 1. Purpose
Define incident response procedures to ensure security events are analyzed and handled consistently.

## 2. Scope
Applies to all endpoints, servers, and network monitoring in the lab environment.

## 3. Incident Categories
- Malware / Execution
- Credential compromise
- Privilege escalation
- DNS tunneling / exfiltration
- Unauthorized access attempts

## 4. Response Process
1) Detection / alert triggers
2) Triage and validation
3) Evidence collection
4) Containment (isolate host / block traffic)
5) Eradication (remove persistence / malware)
6) Recovery (restore services)
7) Lessons learned / improvements

## 5. Evidence / Control Validation
- SIEM investigation screenshots
- Log exports
- Timeline reconstruction

## 6. Review Frequency
Quarterly.
